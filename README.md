# 中国象棋 · 人机对弈

一个**单文件、零依赖**的中国象棋人机对弈网页应用。使用原生 HTML5 / CSS3 / JavaScript 编写，打开即可与 AI 对弈，无需后端、无需安装任何第三方库。

## 在线体验

直接访问 `(https://ffle-art.github.io/chinese-chess/)` 即可在浏览器中对弈。

## 功能特性

- **完整规则引擎**：严格遵循中国象棋官方规则，正确实现
  - 帅/将、仕/士、相/象、马、车、炮、兵/卒的全部走法
  - 蹩马腿、塞象眼、炮翻山、将帅照面、九宫限制、兵卒过河
  - 将军检测、将死判定、困毙判定
- **AI 博弈算法**
  - 极小化极大（Negamax）搜索 + Alpha-Beta 剪枝
  - 局面评估：子力价值 + 位置评分表（PST）+ 过河兵升值
  - 着法排序：MVV-LVA 吃子优先 + 历史启发
  - 迭代加深 + 时间限制，困难档叠加静态搜索（Quiescence）
- **三档难度**
  | 难度 | 搜索深度 | 特点 |
  | --- | --- | --- |
  | 简单 | 2 层 | 高概率随机走子、评估大扰动，适合新手 |
  | 中等 | 3 层 | 正常搜索、轻微扰动，棋力中等 |
  | 困难 | 4 层 + 静态搜索 | 评估精准、无扰动，出子约 1 秒，棋力较强 |
- **对局交互**
  - 选子高亮、可行走法提示、落子
  - 悔棋、走法提示、重新开始
  - 执红先手 / 执黑后手切换
  - 中文棋谱记录（如「炮二平五」「马8进7」）
  - 将军提示、胜负弹窗
- **响应式设计**：桌面左右布局、移动端上下布局，支持触摸操作，高 DPI 屏幕清晰渲染

## 快速开始

直接用浏览器打开 `index.html`（或 `中国象棋人机对弈.html`，二者内容相同）即可开始对局。

## 技术说明

- 棋盘使用 `Int8Array(90)` 表示 9×10 交叉点，走法搜索中快速复制与撤销
- 棋盘与棋子使用 Canvas 2D 绘制，根据 `devicePixelRatio` 适配高分屏
- AI 思考通过 `setTimeout` 异步执行，避免阻塞 UI；搜索带时间限制，单步思考控制在 3 秒以内
- 全部逻辑在客户端完成，无任何网络请求与外部依赖
